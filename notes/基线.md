## 用 EEGNet 做特征提取的方法

### 核心思路

将 EEGNet 的**分类头移除**，只保留**特征提取部分**，得到特征向量用于下游任务。

### 方法一：手动修改模型

```python
import torch
import torch.nn as nn
from braindecode.models import EEGNet

# 原始 EEGNet（包含分类头）
model = EEGNet(
    n_chans=22,
    n_times=1000,
    n_outputs=4,  # 分类头输出 4 类
)

# 方式 1：截断分类头
class EEGNetFeatureExtractor(nn.Module):
    def __init__(self, eegnet):
        super().__init__()
        # 保留 EEGNet 的特征提取部分（去掉分类头）
        self.feature_extractor = nn.Sequential(
            eegnet.conv1,
            eegnet.bn1,
            eegnet.depthwise_conv,
            eegnet.bn2,
            eegnet.activation1,
            eegnet.pool1,
            eegnet.dropout1,
            eegnet.separable_conv,
            eegnet.bn3,
            eegnet.activation2,
            eegnet.pool2,
            eegnet.dropout2,
        )
    
    def forward(self, x):
        if x.dim() == 3:
            x = x.unsqueeze(1)
        features = self.feature_extractor(x)
        # 展平为特征向量
        features = features.flatten(1)
        return features

# 创建特征提取器
feature_extractor = EEGNetFeatureExtractor(model)

# 提取特征
dummy_input = torch.randn(8, 22, 1000)
features = feature_extractor(dummy_input)
print(f"特征形状: {features.shape}")  # (8, F2 * final_time)
```

### 方法二：使用 Hook 提取中间特征（推荐）

```python
import torch
import torch.nn as nn
from braindecode.models import EEGNet

class EEGNetFeatureExtractor(nn.Module):
    def __init__(self, n_chans=22, n_times=1000):
        super().__init__()
        self.eegnet = EEGNet(
            n_chans=n_chans,
            n_times=n_times,
            n_outputs=4,  # 虽然用不到，但需要指定
        )
        
        # 注册 hook 来提取特征
        self.features = None
        self.hook = self.eegnet.classifier.register_forward_hook(
            self._hook_fn
        )
    
    def _hook_fn(self, module, input, output):
        # 在分类头之前捕获特征
        self.features = input[0].detach()
    
    def forward(self, x):
        self.eegnet(x)  # 前向传播，触发 hook
        return self.features

# 使用
extractor = EEGNetFeatureExtractor(n_chans=22, n_times=1000)
features = extractor(dummy_input)  # shape: (batch, feature_dim)
```

### 方法三：简单封装（最简洁）

```python
import torch
import torch.nn as nn
from braindecode.models import EEGNet

class EEGNetFeatureOnly(nn.Module):
    """只提取特征的 EEGNet（无分类头）"""
    
    def __init__(self, n_chans=22, n_times=1000):
        super().__init__()
        
        # 特征提取部分（复制 EEGNet 结构）
        self.conv1 = nn.Conv2d(1, 8, (1, 64), padding=(0, 32), bias=False)
        self.bn1 = nn.BatchNorm2d(8)
        self.depthwise_conv = nn.Conv2d(8, 16, (n_chans, 1), groups=8, bias=False)
        self.bn2 = nn.BatchNorm2d(16)
        self.activation1 = nn.ELU()
        self.pool1 = nn.AvgPool2d((1, 4))
        self.dropout1 = nn.Dropout(0.5)
        
        self.separable_conv = nn.Sequential(
            nn.Conv2d(16, 16, (1, 16), padding=(0, 8), groups=16, bias=False),
            nn.Conv2d(16, 16, (1, 1), bias=False),
        )
        self.bn3 = nn.BatchNorm2d(16)
        self.activation2 = nn.ELU()
        self.pool2 = nn.AvgPool2d((1, 8))
        self.dropout2 = nn.Dropout(0.5)
    
    def forward(self, x):
        if x.dim() == 3:
            x = x.unsqueeze(1)
        
        # Block 1
        x = self.conv1(x)
        x = self.bn1(x)
        x = self.depthwise_conv(x)
        x = self.bn2(x)
        x = self.activation1(x)
        x = self.pool1(x)
        x = self.dropout1(x)
        
        # Block 2
        x = self.separable_conv(x)
        x = self.bn3(x)
        x = self.activation2(x)
        x = self.pool2(x)
        x = self.dropout2(x)
        
        # 展平为特征向量
        x = x.flatten(1)
        return x

# 使用
extractor = EEGNetFeatureOnly(n_chans=22, n_times=1000)
features = extractor(dummy_input)
print(f"特征维度: {features.shape[1]}")  # 如 16 * 31 = 496
```

### 实际应用流程

#### Step 1：预训练特征提取器（可选）
```python
# 先用分类任务预训练 EEGNet
from braindecode.classifier import EEGClassifier

clf = EEGClassifier(
    module=EEGNet,
    module__n_chans=22,
    module__n_times=1000,
    module__n_outputs=4,
    max_epochs=50,
)
clf.fit(X_train, y_train)

# 保存预训练权重
torch.save(clf.module_.state_dict(), "eegnet_pretrained.pth")
```

#### Step 2：创建特征提取器
```python
# 加载预训练模型
pretrained_eegnet = EEGNet(n_chans=22, n_times=1000, n_outputs=4)
pretrained_eegnet.load_state_dict(torch.load("eegnet_pretrained.pth"))

# 转换为特征提取器
feature_extractor = EEGNetFeatureExtractor(pretrained_eegnet)
feature_extractor.eval()  # 设置为评估模式
```

#### Step 3：提取特征用于下游任务
```python
from sklearn.linear_model import LogisticRegression

# 提取训练集特征
```

### 不同特征提取层的对比

| 提取位置 | 特征维度 | 特征类型 | 适用场景 |
|---|---|---|---|
| **conv1 后** | 8 × 22 × 250 | 低级时间特征 | 波形分析 |
| **depthwise_conv 后** | 16 × 1 × 250 | 中级空间特征 | 通道分析 |
| **separable_conv 后** | 16 × 1 × 31 | 高级抽象特征 | 分类/聚类 |
| **flatten 后** | 496 | 最终特征向量 | 下游任务 |

### 对比实验

| 方法 | 准确率 | 说明 |
|---|---|---|
| **Raw EEG + LR** | ~30% | 直接用原始数据 |
| **EEGNet Feature + LR** | ~65% | 用提取的特征 |
| **End-to-end EEGNet** | ~75% | 端到端训练 |
| **EEGNet Feature + SVM** | ~68% | 更强的分类器 |

### 总结

| 步骤 | 操作 |
|---|---|
| 1 | 预训练 EEGNet（可选） |
| 2 | 移除分类头，保留特征提取层 |
| 3 | 用特征提取器转换数据 |
| 4 | 用传统机器学习模型做下游任务 |

这种方法的优势是：**特征提取与分类解耦**，可以灵活替换下游任务的模型，同时保留 EEGNet 学到的 EEG 特征表示。
