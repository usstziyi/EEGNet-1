## `stride_before_pool` 参数详解

这个参数控制的是 **降采样（downsampling）在哪里发生**：是在**卷积层**还是在**池化层**。

### 核心逻辑（来自源码）

```python
if self.stride_before_pool:
    conv_stride = self.pool_time_stride   # 卷积步长=3，做降采样
    pool_stride = 1                        # 池化步长=1，不降采样
else:
    conv_stride = 1                        # 卷积步长=1，不降采样
    pool_stride = self.pool_time_stride   # 池化步长=3，做降采样
```

### 两种模式对比

| 层 | `False`（默认） | `True` |
|---|---|---|
| **卷积层** | stride=1（不降采样） | stride=**3**（降采样） |
| **池化层** | stride=**3**（降采样） | stride=1（不降采样） |

### 数据流对比

以 Block 2 为例（输入 330 → 输出 107）：

**`stride_before_pool=False`**（默认）：
```
Conv2(330 → 321, stride=1) → MaxPool(321 → 107, kernel=3, stride=3)
                                 ↑ 池化做降采样
```

**`stride_before_pool=True`**：
```
Conv2(989 → 327, stride=3) → MaxPool(327 → 325, kernel=3, stride=1)
                          ↑ 卷积做降采样
```

### 两种模式的时间维度变化

| 步骤 | `False`（默认） | `True` |
|---|---|---|
| 输入 | 1000 | 1000 |
| CombinedConv | 991 | 991 |
| Pool1 | **330** | **989** |
| Conv2 | 321 | 327 |
| Pool2 | **107** | **325** |
| Conv3 | 98 | 106 |
| Pool3 | **32** | **104** |
| Conv4 | 23 | 32 |
| Pool4 | **7** | **30** |
| 分类头 kernel | (7, 1) | (30, 1) |
| **总参数量** | **282,879** | **301,279** |

### 区别总结

| 方面 | `False`（默认） | `True` |
|---|---|---|
| 降采样位置 | 池化层 | 卷积层 |
| 特征图压缩 | 更激进（330→107→32→7） | 更温和（989→325→104→30） |
| 信息保留 | 压缩更彻底 | 保留更多时间细节 |
| 参数量 | 更少（282K） | 更多（301K） |
| 适用场景 | 通用 | 需要更丰富的时间特征时 |

### 直觉理解

- **`False`（默认）**：先提取特征（卷积不降采样），再压缩（池化降采样）。这样特征提取阶段能看到更丰富的信息，压缩在最后一步做。
- **`True`**：先压缩（卷积降采样），再提取特征。这样计算更高效（因为中间特征图更小），但可能损失一些细节。

两者在最终分类头的区别很明显：`False` 模式下分类头 kernel 只有 `(7, 1)`，而 `True` 模式下有 `(30, 1)`，因为后者保留了更多时间维度的信息。
