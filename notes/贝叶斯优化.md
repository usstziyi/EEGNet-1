# 贝叶斯优化（Bayesian Optimization）完整讲解
结合你当前场景：**模型超参调优（替代网格搜索/随机搜索），EEG脑机实验、深度学习调参非常常用**
先建立对比：
- 网格搜索：暴力穷举，不利用历史信息；
- 随机搜索：随机采样，也不利用历史结果；
- **贝叶斯优化：充分利用之前每一组参数的实验结果，智能预测下一组最可能最优的超参，循序渐进搜索**。

## 一、先理解核心痛点
假设你要调参：学习率、batch size、dropout、正则系数。
网格搜索：划定范围，全部挨个试，不管哪些参数效果好、哪些差，浪费算力。
贝叶斯优化思想：
> “我已经测试过A、B、C三组参数，得到对应的精度；我基于历史数据，**建立一个代理模型预测超参和模型性能之间的关系**，挑选「最有可能取得更高精度」的下一组参数去训练，而不是盲目采样。”

## 二、两大核心组件（贝叶斯优化标准框架）
### 1. 代理模型（Surrogate Model）
用来近似拟合：$f(超参数组合) = 交叉验证得分$
真实目标函数$f$就是你的模型训练（成本极高，跑一次要几分钟/几十分钟）。
代理模型是低成本近似函数，可以快速预测任意参数对应的效果。
常用代理模型：
- 高斯过程 GP（传统经典，早期贝叶斯优化）
- 树结构 Parzen 估计器 TPE（Optuna 默认！深度学习主流）
- 随机森林

> 你平时使用的 **Optuna** 底层默认就是 **TPE**，属于贝叶斯优化分支。

### 2. 采集函数（Acquisition Function）
平衡两个目标，用来选出下一组待测试参数：
1. **探索（Exploration）**：去参数空间里还没尝试过的区域，防止局部最优；
2. **利用（Exploitation）**：在当前已知表现不错的参数附近精细搜索。

常见采集函数：EI（期望改进，Expected Improvement），最通用。

## 三、完整迭代流程（循环执行）
1. **初始化**：随机测试少量几组超参数，拿到初始样本 `(参数，得分)`
2. **训练代理模型**：使用所有已经跑完的历史数据，拟合参数→性能的映射
3. **采集函数挑选候选**：基于代理模型，选出综合潜力最高的一组超参
4. **真实评估**：使用这组超参训练你的EEG模型，运行K折交叉验证，得到真实分数
5. **存入历史记录**，回到步骤2，持续循环直到达到设定最大迭代次数

直观区别：
网格搜索路线：提前排好所有选手，按顺序挨个打分
贝叶斯优化路线：先看已经打分选手，推测下一个最有可能拿高分的选手优先上场

## 四、贝叶斯优化 VS 网格/随机搜索
|方式|核心逻辑|算力消耗|适用场景|
| ---- | ---- | ---- | ---- |
|网格搜索|暴力遍历全部组合|极高；参数维度上升爆炸|少量离散超参，小搜索空间|
|随机搜索|随机采样，无信息反馈|中等；效率一般|初步大范围试探|
|贝叶斯优化|利用历史结果智能选参|低，**同等算力下更容易找到最优值**|深度学习、EEG模型、搜索空间大、训练耗时大（你的场景首选）|

> 关键优势：**当单次模型训练成本很高（EEG深度学习模型训练慢），贝叶斯优化优势巨大**。

## 五、两个极易踩坑的重点（结合你的交叉验证知识）
### 1. 内部评估依然要用K折交叉验证
每一组候选超参，不能只用一次训练/测试划分评估！
和GridSearchCV一样：每组参数内部运行K折CV，用平均得分作为评价指标，避免单次划分带来的运气误差。

### 2. 严防数据泄露！和之前标准化规则一致
如果你使用Optuna做调参，**每一次trial内部必须构建Pipeline**，保证每一折内部单独拟合StandardScaler，不要全局预处理。

### 3. 严谨实验：嵌套交叉验证 Nested CV
外层：划分独立测试集（最终只使用一次）
内层：在训练集内，用Optuna贝叶斯优化+K折挑选最优超参
❌禁止：调参过程中见过的数据拿来做最终测试，造成乐观偏差。

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
import numpy as np

# 1. 定义目标函数：一次trial = 一组超参，返回交叉验证平均分
def objective(trial):
    # 定义搜索空间
    params = {
        "C": trial.suggest_float("C", 1e-3, 1e3, log=True),
        "kernel": trial.suggest_categorical("kernel", ["linear", "rbf"])

    # Pipeline！解决标准化数据泄露
    pipe = Pipeline([
        ("scaler", StandardScaler()),
        ("svm", SVC(**params))
    ])

## 七、优缺点总结
✅优点
1. **高效**：利用历史信息引导搜索，在有限迭代次数下更容易找到优秀超参；
2. 支持连续参数（学习率这种浮点数）、离散参数、对数空间搜索；
3. Optuna框架轻量化，广泛用于脑电、深度学习论文；
4. 支持早停、剪枝（Pruning）：中途发现模型效果很差，可以直接终止训练，节省算力。

❌缺点
1. 存在少量算法开销（代理模型持续更新），但相比于模型训练耗时几乎可以忽略；
2. 理论上不能保证找到全局最优，只是概率上更容易找到优质参数；
3. 调参本身新增少量超参（迭代次数、采样器选择）。

## 八、拓展补充
1. **剪枝 Pruning（Optuna强大功能）**
训练神经网络时，不需要完整跑完epoch。如果前几个epoch效果很差，直接提前终止这个trial，极大节省时间，非常适合EEG深度学习模型。

2. 什么时候选哪种调参方案？
- 超参≤3个、范围小：网格搜索
- 初步大范围摸底：随机搜索
- 深度学习、模型训练慢、超参较多（你的EEG2Text/脑电分类）：**Optuna贝叶斯优化**
